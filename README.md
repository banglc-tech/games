# Góc game · banglc-tech

Tất cả game nằm chung repo này, mỗi game một thư mục `/<tên-game>/index.html`, chạy trên GitHub Pages: https://banglc-tech.github.io/games/

- Trang danh mục: `index.html` (sửa mảng `GAMES` để thêm game).
- Game camera dùng MediaPipe Pose (jsDelivr), game 3D dùng three.js r128 (cdnjs). Còn lại là HTML/CSS/JS thuần, không cần build.
